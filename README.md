# Torneira-dorge

Este repositório contém uma implementação de exemplo para uma "torneira" (faucet) de Dogecoin usando FaucetPay. Ele separa a lógica sensível (chave de API) no servidor e fornece um frontend simples que chama um endpoint seguro.

IMPORTANTE: Não comite a sua chave de API. Use variáveis de ambiente e configure secrets no serviço de hospedagem.
